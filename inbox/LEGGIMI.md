# Inbox biglietti

Qui si lasciano biglietti e conferme da inserire nel planner: PDF, screenshot, mail salvate o testo
incollato in un file `.txt`. Poi basta dire a Claude «guarda l'inbox».

Claude legge ogni file, lo confronta con Gmail, inserisce i dati nella sezione giusta del planner
(hotel, trasporti o agenda) e sposta il file in `fatti/`.

Tutto ciò che sta qui resta **solo su questo Mac**: la cartella è esclusa da git perché il repository
è pubblico. PIN, codici di accesso e numeri di passaporto non vengono copiati nel planner.
